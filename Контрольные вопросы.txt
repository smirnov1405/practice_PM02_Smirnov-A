2. Почему выбран стек: Python + MySQL + tkinter? Какие альтернативы могли быть?

Python выбран за простой синтаксис и богатую экосистему библиотек. MySQL - надежная бесплатная СУБД с широкой распространенностью. tkinter - встроенная библиотека Python, не требует дополнительной установки.
Альтернативы: вместо Python можно использовать Java, C# или PHP; вместо MySQL - PostgreSQL, SQLite или MongoDB; вместо tkinter - PyQt, Kivy или веб-интерфейс на Flask/Django.

3. Что такое ER-диаграмма? Для чего она нужна?

ER-диаграмма (Entity-Relationship) - графическое представление структуры базы данных, показывающее сущности (таблицы в виде прямоугольников), атрибуты (поля в виде овалов) и связи между сущностями (в виде ромбов).
Она нужна для визуализации структуры БД, проектирования перед созданием таблиц и документирования базы данных.

4. Какие типы связей между таблицами существуют? Приведите примеры из своего варианта.

Существуют три основных типа связей: один к одному (1:1) - например, человек и паспорт; один ко многим (1:N) - например, категория и товары; многие ко многим (N:M) - например, студенты и курсы.
Из вашего варианта: Проект и Модули (связь 1:N), Разработчик и Задачи (связь 1:N).

5. Что такое Git? Чем отличается git commit от git push?

Git - распределенная система контроля версий для отслеживания изменений в коде.
git commit сохраняет изменения в локальном репозитории на вашем компьютере, не требует интернета. git push отправляет изменения в удаленный репозиторий (GitHub) и требует интернет-соединения.
Простая аналогия: commit - сохранение игры на вашем компьютере, push - синхронизация сохранения с облаком.

6. Как проверить, что Python установлен и tkinter работает?

Для проверки Python: команда python --version
Для проверки tkinter: python -c "import tkinter; tkinter._test()" - должно открыться тестовое окно
Или проще: python -c "import tkinter; print('tkinter работает')"

7. Какие меры безопасности нужно соблюдать при работе за компьютером?

Электробезопасность: заземление, работа сухими руками, качественные провода
Пожарная безопасность: обеспечить вентиляцию, не загромождать оборудование
Санитарные нормы: делать перерывы каждые 45-60 минут, соблюдать правильную посадку
Защита данных: установить антивирус, использовать сложные пароли, делать резервное копирование
Режим труда: правильное освещение, расстояние до монитора 50-70 см

8. Что означает IP-адрес 127.0.0.1?

127.0.0.1 - это localhost (локальный компьютер). Он используется для тестирования без выхода в сеть, пакеты с этим адресом не уходят в интернет. Псевдоним - localhost. Весь диапазон 127.0.0.0 - 127.255.255.255 зарезервирован для loopback-адресов.

9. Как добавить файл в репозиторий Git (последовательность команд)?

1. git init - инициализировать репозиторий
2. git add имя_файла - добавить файл в отслеживание
3. git commit -m "Сообщение" - сделать коммит
4. git remote add origin URL - связать с удаленным репозиторием (если нужно)
5. git push origin main - отправить на GitHub

10. Зачем нужен файл README.md в проекте?

README.md - это визитная карточка проекта. Он содержит название проекта, описание цели и функций, инструкцию по установке, руководство по использованию, скриншоты примеров работы и контактную информацию авторов.
Он нужен для документирования проекта, представления его другим разработчикам и помощи новым участникам в быстром освоении.
